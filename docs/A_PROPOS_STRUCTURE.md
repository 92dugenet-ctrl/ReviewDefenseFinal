# ReviewDefense — V16 — À propos

## Intention

La page À propos explique pourquoi ReviewDefense existe sans devenir une page de manifeste éditorial long format.

Elle utilise une composition spatiale : petits objets, fragments d'interface, annotations et cartes répartis dans une page claire.

## Principes

- Pas de typographie géante occupant tout l'écran.
- Pas de long parcours vertical comme « Comment ça marche ».
- Pas d'orbite comme la page Sécurité V15.
- Pas de dashboard massif.
- Pas de promesse de suppression automatique.
- Le système analyse et recommande ; l'utilisateur décide.

## Séquence

1. Pourquoi ReviewDefense existe.
2. Un avis négatif n'est pas nécessairement faux ou signalable.
3. Comprendre avant de choisir une action.
4. Le contexte change la décision.
5. Le rôle de l'IA : rendre le raisonnement lisible.
6. Ce que ReviewDefense refuse : automatisme et confusion entre score et vérité.
7. Méthode : Observer → Comprendre → Décider → Agir.
8. Conclusion et CTA.

## Interaction

Les interactions restent locales et discrètes : sélection d'une action, micro-déplacement des cartes, survol de la méthode.

Aucune connexion backend n'est introduite.
