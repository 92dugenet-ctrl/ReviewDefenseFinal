# ReviewDefense — Design System

## Direction

Interface publique premium, calme et lisible. Environ 80 % de calme visuel et 20 % d'information graphique. Chaque page conserve son interaction propre sans devenir un template SaaS répétitif.

## Typographie

- Police principale : Inter.
- Graisses utilisées : 400, 500, 600, 700.
- H1 : 42–72 px, 600, line-height 1.02, letter-spacing -0.04em.
- H2 : 30–48 px, 600, line-height 1.08, letter-spacing -0.03em.
- H3 : 22 px, 600, line-height 1.2.
- Corps : 16 px, line-height 1.65.
- Labels : 11 px, 600, uppercase, letter-spacing 0.12em.
- Nombres : tabular-nums et graisse 600.

## Couleurs

- Fond : #F8FAFC.
- Surface : #FFFFFF.
- Texte principal : #0B1630.
- Texte secondaire : #536078.
- Bleu principal : #2563EB.
- Bleu doux : #EAF2FF.
- Bordure : #E2E8F0.
- Succès : #16856A.
- Avertissement : #B7791F.
- Suspicion : #C45A4A.
- Danger : #B42318.

## Composants

- Cartes : rayon 16 px.
- Petites interfaces : rayon 12 px.
- Visuels graphiques : rayon 20 px.
- Ombre par défaut : 0 8px 30px rgba(11,22,48,.06).
- Éviter les grandes cartes à rayon 32 px systématiques.
- Bouton primaire : navy + texte blanc.
- Bouton secondaire : transparent + bordure #CBD5E1.

## Espacement

Échelle : 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128 px.

## Animation

- Rapide : 160 ms.
- Normale : 280 ms.
- Lente : 500 ms.
- Transformation narrative : 500–800 ms.
- Easing : cubic-bezier(.22,1,.36,1).
- Toujours respecter prefers-reduced-motion.
- Les animations doivent clarifier une transformation, une apparition ou un changement d'état.

## Règles produit

- Le système recommande. Vous décidez.
- Un avis négatif n'est pas automatiquement faux ou signalable.
- Le produit distingue répondre, examiner, signaler et ne rien faire.
- Le frontend public ne modifie pas les interfaces backend/admin.
