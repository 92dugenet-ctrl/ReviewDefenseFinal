# ReviewDefense — Frontend commercial

Ce dossier regroupe le socle actuel du frontend commercial ReviewDefense.

## Architecture
- `pages/` : pages du site commercial.
- `sections/` : sections modulaires propres aux pages.
- `components/` : composants réutilisables, notamment header et footer.
- `styles/` : styles globaux.
- `scripts/` : scripts globaux.
- `assets/` : ressources visuelles.
- `legal/` : pages légales.
- `docs/` : documentation structurelle utile au projet.

## Périmètre
Ce frontend concerne uniquement la partie commerciale/public de ReviewDefense.
Le backend et les interfaces internes ne font pas partie de ce lot.

- `docs/SIGNALEMENT_STRUCTURE.md` — structure de la page Signalement.
